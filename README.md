# 🏰 AI館ダンジョン

ローグライク風のブラウザゲームです。地下5階に眠る👑伝説の宝物を目指しましょう。

🎮 **遊ぶ → https://kikyujin.github.io/AIhouse-dungeon/**

---

## 目的

地下1階からダンジョンに潜り、地下5階の最奥にある👑を手に入れればクリアです。
敵を全部倒す必要はありません。逃げるのも立派な戦略です。

---

## 操作

| キー | 動作 |
|---|---|
| W / ↑ | 上に移動 |
| S / ↓ | 下に移動 |
| A / ← | 左に移動 |
| D / → | 右に移動 |
| Q | 左上（斜め） |
| E | 右上（斜め） |
| Z | 左下（斜め） |
| C | 右下（斜め） |
| R | リトライ（ゲームオーバー / クリア時） |

スマホはD-Padボタンで操作できます。

- 🚪 閉じたドアにぶつかると開きます（1ターン消費）
- 🕳️ 下り階段に乗ると次の階へ
- ⬆️ 上り階段に乗ると前の階へ（マップは保持されます）
